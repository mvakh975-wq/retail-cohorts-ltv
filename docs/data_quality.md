# Качество данных

Проверено на полном файле Online Retail II (1 067 371 строка накладных, 01.12.2009–09.12.2011).
Код очистки — [`src/clean.py`](../src/clean.py), отчёт по шагам выводится в ноутбуке.

| Проверка | Результат | Решение |
|---|---|---|
| Строки без `Customer ID` | 243 007 (13,7% выручки) | Отброшены: без клиента когорту не построить |
| Полные дубли строк | 26 479 после удаления строк без клиента | Отброшены |
| Сервисные коды (`POST`, `DOT`, `M`, `BANK CHARGES`, `AMAZONFEE`, `ADJUST`, тестовые товары и др.) | 3 641 | Отброшены: это доставка, комиссии и корректировки, а не товары |
| Цена ≤ 0 | 61 | Отброшены: бесплатные позиции и списания |
| Накладные на `C` (возвраты) | 7 283 накладные | Оставлены: уменьшают выручку, но покупкой не считаются |
| Накладные на `A` (списание долга) | 6 строк | Отброшены на шаге «без клиента» |
| Последний месяц | данные до 09.12.2011 | Декабрь 2011 неполный — не входит в расчёты |
| Первые месяцы данных | клиенты, впервые замеченные в 2010, — часто давние | Первые 12 месяцев — окно истории, когорты с 12.2010 |
